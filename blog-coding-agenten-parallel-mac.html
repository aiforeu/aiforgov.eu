Coding-Agenten parallel auf dem Mac nutzen: Wie teilt man die Arbeit auf?

Zwei Coding-Agenten lassen sich gut parallel einsetzen, wenn die Aufträge eigene Ergebnisse und klar getrennte Arbeitsbereiche haben. Zwei Terminalfenster allein trennen die Dateien noch nicht. IVE bündelt die Sitzungen auf dem Mac, zeigt ihren Status und bringt Rückfragen zum jeweiligen Auftrag zurück.

24. November 2026 · AIFOREU · 2 Min. Lesezeit

Zwei Aufträge aus demselben Fehlerbericht ableiten

Angenommen, ein CSV-Import bricht bei leeren Zeilen ab und die Hilfeseite beschreibt das erwartete Dateiformat nur ungenau. Ein Auftrag an Codex könnte lauten: „Behandle leere Zeilen im Import und ergänze einen Test mit einer leeren Zeile zwischen zwei Datensätzen.“ Claude Code bekommt die Hilfeseite: „Ergänze ein importierbares Beispiel mit den Pflichtspalten und dokumentiere die vorhandene Fehlermeldung für eine fehlende Spalte.“ Beide Agenten können mit denselben Beispieldaten anfangen.

Das Team legt vorher fest, welche Pflichtspalten gelten. Ist diese Entscheidung offen, kann der zweite Agent zunächst die bestehende Anleitung und offene Fragen zusammentragen. Sonst beschreibt die Hilfe womöglich ein Verhalten, das sich während der Implementierung noch ändert.

Gehören die Sitzungen zur gleichen Arbeitskopie?

Prüfen Sie vor dem Start Projektpfad und Branch jeder Sitzung. Arbeiten beide Agenten im selben Ordner, sehen sie Änderungen des jeweils anderen. Für getrennte Änderungen bietet Git mit Worktrees mehrere Arbeitsverzeichnisse desselben Repositorys. Weisen Sie jedem schreibenden Auftrag ein eigenes Arbeitsverzeichnis mit eigenem Branch zu. Die beiden Ergebnisse lassen sich danach einzeln prüfen und gemeinsam testen.

Bei einer reinen Recherche kann die zweite Sitzung auch nur lesen. Benennen Sie dafür den zu untersuchenden Stand im Auftrag. Andernfalls kann ein Bericht bereits eine zwischenzeitliche Änderung der schreibenden Sitzung beschreiben.

Rückfragen dort beantworten, wo sie entstehen

In der IVE-Produktansicht hat jede Sitzung einen eigenen Zustand. Fragt der Import-Agent, ob Zeilen mit Leerzeichen ebenfalls als leer gelten, antworten Sie in genau dieser Sitzung. Der Auftrag für die Hilfeseite kann weiterlaufen. Ändert Ihre Antwort den fachlichen Vertrag, geben Sie die Entscheidung anschließend auch an die zweite Sitzung weiter.

Zum Abschluss importiert eine Person die Beispieldatei aus der fertigen Anleitung mit dem geänderten Programm. Dieser gemeinsame Test findet Widersprüche, die in zwei einzeln plausiblen Ergebnissen verborgen bleiben. Wie Sie die Änderungen im Detail prüfen, beschreibt der Leitfaden für Code-Reviews mit KI-Agenten.
