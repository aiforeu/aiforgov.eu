Desktop-Automatisierung ohne API für bestehende Fachsoftware

Desktop-Automatisierung ohne API eignet sich für wiederkehrende Eingaben in eine Fachanwendung, die Mitarbeitende heute von Hand bedienen. Vor einem Pilot sollten Sie zeigen können, welches Ergebnis gespeichert werden soll, wie ein bestehender Datensatz erkannt wird und wer bei einer unklaren Zuordnung übernimmt.

24. November 2026 · AIFOREU · 2 Min. Lesezeit

Was soll nach der Eingabe im System stehen?

Eine Vertriebsassistenz erhält eine Rückrufbitte. In der Kundenliste existiert der Betrieb bereits. Erwartet wird eine neue Aufgabe am richtigen Kundenkonto mit Rückrufnummer und zuständiger Person. Ein zweiter Kundeneintrag wäre ein Fehler, auch wenn alle Felder darin richtig ausgefüllt sind. Beschreiben Sie den Sollzustand deshalb so, dass eine Kollegin ihn später direkt in der Anwendung kontrollieren kann.

Dieses Beispiel knüpft an die Anfrageübertragung von AIFOREU an. AnyWatch ist das Desktop-Modul von AIFOREU Workforce. Welche Arbeitsschritte in Ihrer Anwendung freigegeben werden können, hängt unter anderem von Ihren Zugriffsrechten, den verfügbaren Feldern und den vereinbarten Ausnahmen ab.

Welche Anbindung passt zu Ihrer Anwendung?

Fragen Sie die IT zuerst, ob die Software für Kundenaufgaben bereits eine gepflegte Schnittstelle oder einen freigegebenen Import anbietet. Ein vorhandener Import kann für eine ganze Liste gut passen. Für eine einzelne Rückrufbitte hilft er wenig, wenn sich darüber nur neue Kontakte anlegen lassen. Dann lohnt ein Versuch über die Oberfläche. Halten Sie fest, welche Eingaben mit dem vorgesehenen Benutzerkonto tatsächlich möglich sind.

Drei Fälle, die Sie vor dem Start durchspielen sollten

  1. Zwei ähnlich benannte Kunden. Legen Sie fest, welche Kennung einen Treffer eindeutig macht. Fehlt sie, soll der Vorgang mit beiden möglichen Treffern zur Prüfung gehen.
  2. Ein unterbrochener Speichervorgang. Suchen Sie vor einem zweiten Versuch nach der Aufgabe. So lässt sich testen, ob ein Wiederanlauf versehentlich zwei Rückrufe erzeugt.
  3. Ein gesperrter Datensatz. Erproben Sie, wer die Meldung erhält und ob die Angaben aus der ursprünglichen Anfrage für die manuelle Bearbeitung verfügbar bleiben.

Der beste Abnahmetest ist der Blick der Vertriebsassistenz ins Kundenkonto. Dort sollte genau eine richtige Aufgabe liegen oder eine offene Rückfrage mit zuständiger Person sichtbar sein. Benennen Sie für den betreuten Pilot eine Person, die unklare Treffer übernimmt und über die Freigabe entscheidet. Bringen Sie für das Gespräch zur Desktop-Automatisierung eine Beispielanfrage mit, bei der Ihr Team heute nachfragen muss.
